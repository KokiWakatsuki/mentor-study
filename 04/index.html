temperatures = [9.0, 7.0, 11.0]highest = temperatures[0]for t in temperatures: if t > highest: highest = tprint(highest)

最高を求める

入力は受け取り済み（temperatures にリストで）．続きを書く

問1　本日の最高

温度のリストから最高を出力．max( ) は使わない

入力例（1行目は記録の数）
3
9.0
7.0
11.0
出力例
11.0
ヒント

③ のコードの2〜6行目と同じ形
最初の最高を 0 にすると，全部マイナスのときに失敗

解答例
highest = temperatures[0]for t in temperatures: if t > highest: highest = tprint(highest)

問2　最低と低温の回数（続き）

1行目に最低，2行目に 8.0 未満の回数を出力

入力例
4
9.0
7.0
11.0
7.5
出力例
7.0
2
ヒント

回数は count = 0 から始め，低温のたびに count = count + 1

解答例
lowest = temperatures[0]count = 0for t in temperatures: if t < lowest: lowest = t if t < 8.0: count = count + 1print(lowest)print(count)
