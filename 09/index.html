4

動かして確認

VS Code ブラウザ

  1. センサーを止める（2つ目のターミナルで Ctrl + C）

    理由：自分で送る記録だけで，数の増え方を見るため

  2. 提案の枝に移動3つ目のターミナル

    git fetch && git switch ai/cold-count

  3. 一覧を「更新」→ 3号棟の「低温の回数」を控える

  4. API の試験画面で，3号棟に 7.9℃ を送る

    http://localhost:8000/docs →「POST /api/readings」→「Try it out」
    → Request body を次に置き換え →「Execute」

    {"house_id": 3, "temperature": 7.9, "humidity": 70}

    下に 200 と {"ok": true} → 送信成功
    → 一覧を「更新」→ 3号棟の回数

  5. 同じ手順で 8.0℃ を送る

    {"house_id": 3, "temperature": 8.0, "humidity": 70}

8.0℃ を送った後の回数は，② で決めた動作どおり？

違う　札は「正常」なのに，回数は増える
原因：<=（以下）．低温の判定は <（未満）

7.9℃ で +1，8.0℃ でも +1（期待と違う）
