同じ行を，2人が変えたら

園主から，警告文について2つの要望．先輩と自分で分担した

元の文…暖房と換気窓を確認してください．
先輩（扉も）…暖房・換気窓・扉を確認してください．
自分（すぐに）…暖房と換気窓をすぐに確認してください．

先輩の変更が main に入った後，自分の枝に main を取り込むと？

自動では取り込めず，人が直す　同じ行が別々に変わり，どちらを残すか Git には決められない
これがコンフリクト．失敗ではなく，相談の合図

正解は「両方の意図を満たす1行」
…暖房・換気窓・扉をすぐに確認してください．

起きる理由と，目指す1行を確認

コンフリクトの解消

VS Code

  1. main から自分の枝を作る

  2. static/list.js で「確認してください」→「すぐに確認してください」→ Ctrl + S

    Ctrl + F →「確認してください」

  3. 記録

  5. main の最新を，自分の枝に取り込む

    CONFLICT (content): Merge conflict in static/list.js → 予定どおり

  6. static/list.js を開く → 重なった所（色付きの5行）

    static/list.js
    現在の変更を採用 | 入力側の変更を採用 | 両方の変更を採用 | 変更の比較 <<<<<<< HEAD (現在の変更) alertBar.textContent = `… 暖房と換気窓をすぐに確認してください．`; ======= alertBar.textContent = `… 暖房・換気窓・扉を確認してください．`; >>>>>>> origin/main (入力側の変更)
    緑（現在の変更）自分の枝の文．「すぐに」
    青（入力側の変更）main の文．先輩の「扉」
    <<< === >>>Git が付けた区切りの印．最後は全部消す

  7. <<<<<<< の行の先頭から，>>>>>>> の行の末尾までをドラッグで選択 → 貼り付け → Ctrl + S
